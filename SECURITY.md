# Security Policy / Политика безопасности

## 1. Supported Versions / Поддерживаемые версии
Мы поддерживаем безопасность актуальной релизной ветки (`beta` / `main`).

| Компонент | Версия / Ветка | Статус поддержки |
| :--- | :--- | :--- |
| GhostAI Native Client (C++17) | Release x64 (ветка `beta`) | ✅ Поддерживается |
| Cloudflare CDN Relay | worker.js (v1.0+) | ✅ Поддерживается |

---

## 2. Reporting a Vulnerability / Сообщение об уязвимости
Мы серьезно относимся к безопасности проекта и ценим ответственное раскрытие уязвимостей (Responsible Disclosure).

Если вы обнаружили потенциальную уязвимость в безопасности (уязвимости драйвера, утечки памяти или криптографические слабости):

1. Направьте отчет через раздел GitHub Security Advisories репозитория с пометкой `[SECURITY VULNERABILITY]`.
3. В отчете укажите:
   - Описание уязвимости и потенциального вектора эксплуатации;
   - Шаги для воспроизведения (PoC / лог / шаги);
   - Рекомендуемый способ устранения (если известен).

Мы подтвердим получение отчета в течение 48 часов и предоставим информацию о планируемом сроке исправления.

---

## 3. Архитектурные принципы безопасности
- **Криптографическая изоляция**: Секреты пользователя не хранятся в открытом виде и шифруются с использованием Windows DPAPI.
- **Статическая линковка (`/MT`)**: Отсутствие внешних runtime-зависимостей исключает атаки класса DLL Hijacking.
- **Маскировка процесса и DACL**: Ограничение дескрипторов потоков и процесса предотвращает вмешательство сторонних недоверенных процессов в память приложения.
